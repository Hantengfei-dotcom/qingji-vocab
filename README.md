# 轻记单词

纯静态英语单词网站，可直接发布到 GitHub Pages。无需服务器、数据库或后台账号。

## 词库与功能

- 大学英语四六级综合词库：6,661 个去重单词。
- 雅思词库：22 章、3,632 条词条。
- 单词卡、词义选择、拼写练习、单词搜索和浏览器发音。
- 学习进度保存在使用者自己的浏览器中，可导出和导入进度文件。

词库从原网站公开页面整理而来。GitHub Pages 不提供账号或跨设备自动同步；更换浏览器前请先导出进度。

## 发布到 GitHub Pages

将本目录的文件放在 GitHub 仓库根目录，在仓库 **Settings → Pages** 中选择 **Deploy from a branch**，分支选 **main**，目录选 **/(root)**，保存后等待 GitHub 给出公开链接。

## 本地预览

在本目录运行 `python -m http.server 8765`，然后打开 `http://127.0.0.1:8765/`。直接双击 `index.html` 时，浏览器通常会阻止读取本地 JSON 词库。
